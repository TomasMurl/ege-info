# Задания на циклы и итерирование

Цель заданий — понять, по каким объектам можно итерироваться и что именно
получает цикл на каждом шаге.

---

## Задание 1. Итерация по range
Дано число `n`.

Выведи все числа от `0` до `n - 1`, каждое в новой строке.

Подсказка: `range(n)`

---

## Задание 2. range с шагом
Выведи все чётные числа от `0` до `20` включительно, используя `range`.

Подсказка: третий аргумент `range`

---

## Задание 3. Итерация по строке
Дана строка `"DevOps"`.

Выведи каждый символ строки на отдельной строке.

---

## Задание 4. Подсчёт символов
Дана строка.

Посчитай, сколько раз в ней встречается буква `'a'`.

---

## Задание 5. Итерация по списку
Дан список чисел:

```python
[3, 7, 2, 9, 4]
```

Выведи каждый элемент списка, увеличенный на 1.

---

## Задание 6. Индекс и элемент
Дан список строк:

```python
["docker", "kubernetes", "terraform"]
```

Выведи элементы в формате:

```python
0: docker
1: kubernetes
2: terraform
```

---

## Задание 7. Итерация по строке с условием
Дана строка, содержащая буквы и цифры.

Выведи только цифры, которые есть в строке.

Пример:
```python
"a1b2c3" → 1 2 3
```

## Задание 8. Вложенные циклы
Выведи таблицу умножения от 1 до 5.

Формат не важен, достаточно вывести произведения.

## Задание 9. Итерация по словарю
Дан словарь:

```python
{
    "name": "Alex",
    "age": 25,
    "role": "admin"
}
```

Выведи все пары ключ-значение в формате:
```python

```

## Задание 10. Управление циклом
Дан список чисел.

Обрабатывай числа по порядку:

- отрицательные числа пропускай
- при встрече 0 останавливай цикл

Подсказка: `continue` и `break`
