## Задание 1. Индекс и длина слова

Дан список строк:

```python
["aws", "docker", "kubernetes", "terraform"]
```

```text
0: aws (3)
1: docker (6)
2: kubernetes (10)
3: terraform (9)
```

## Задание 2. Элементы с чётным индексом  
(обязательно использовать range(len(...)))

Дан список чисел:

```python
numbers = [10, 15, 20, 25, 30]
```

Выведи только элементы с чётным индексом:

```text
index 0 -> 10
index 2 -> 20
index 4 -> 30
```

Условие:  
использовать цикл:

```python
for i in range(len(numbers)):
```
