1. Сумма чисел от 1 до N

Ввести число N. Вывести сумму всех чисел от 1 до N.

2. Проверка чётности

Ввести число. Если оно чётное — вывести "YES", иначе "NO".

3. Максимум из трёх чисел

Ввести три числа. Вывести самое большое.

4. Количество положительных чисел

Ввести N чисел по очереди. Посчитать, сколько из них положительные.

5. Таблица умножения для числа

Ввести число X. Вывести таблицу умножения X от 1 до 10.

6. Сумма чётных чисел от 1 до N

Ввести N, вывести сумму всех чётных чисел до N.

7. Подсчёт цифр числа

Ввести натуральное число. Посчитать, сколько в нём цифр.

8. Обратный отсчёт

Ввести число N. Вывести числа от N до 1.

9. Количество нечётных чисел в диапазоне

Ввести два числа A и B. Посчитать количество нечётных чисел между ними включительно.

10. Минимум из N чисел

Ввести N, затем N чисел. Найти минимальное.

11. Проверить делимость

Ввести два числа A и B. Проверить, делится ли A на B без остатка.

12. Найти первое число больше 100

Ввести N чисел. Найти первое, которое больше 100. Если нет — вывести "NONE".

13. Сумма цифр числа

Ввести число. Вывести сумму всех его цифр.

14. Количество нулей

Ввести N чисел. Посчитать, сколько среди них равны нулю.

15. Возведение в степень простым циклом

Ввести числа A и B. Посчитать Aⁿ с помощью цикла.

16. Вывести все делители числа

Ввести число N. Вывести все его делители.

17. Найти произведение чисел от 1 до N

Ввести число N. Вывести факториал (произведение от 1 до N).

18. Проверить число на простоту

Ввести число N. Проверить, является ли оно простым.

19. Количество чисел, которые больше предыдущего

Ввести N, затем N чисел. Посчитать, сколько чисел больше, чем число перед ним.

20. Найти два максимальных числа

Ввести N чисел. Вывести два самых больших (в порядке убывания).
